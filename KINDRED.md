# Kindred — AI Senior Care Platform

## Repository
- GitHub: https://github.com/MuhammadFarid1990/Kindredseniorcitizen
- App branch: `claude/build-new-app-SZF0v`
- App directory: `kindredcare-ai/`
- Local clone: `/home/user/Kindredseniorcitizen`

## Stack
- Next.js 15 + React 19
- Supabase (auth, database, edge functions)
- Anthropic Claude API (AI features)
- Tailwind CSS + Radix UI
- pnpm

## Features
- Senior user dashboard
- Guardian dashboard ("Is my loved one okay today?")
- Senior care center tracking dashboard
- Medication management (CRUD)
- Calendar events & reminders
- Doctor & emergency contact management
- AI-powered health briefings (voice + text)
- Alerts & notifications
- Safety evaluation pipeline
